# 杭州五强电子有限公司 · 中英雙語網站

依原站 `http://www.hzwqdz.com/public.asp?base_id=43` 的內容重製。原站為 2001 年前後風格的 ASP 版型，本版重新編排資訊架構、字體層級與視覺語言，內容全部取自原站（公司簡介、產品規格、解決方案文件、最新動態、客戶服務、人才招聘、聯絡方式），並補上英文版本。

## 檔案結構

```
index.html                  單頁式網站（含中英雙語內容與 SEO 標記）
assets/css/style.css        設計系統與版面（已內嵌 JetBrains Mono，離線可讀）
assets/js/app.js            語言切換、行動版選單、型號篩選、文件搜尋、進場動畫
assets/img/                 原廠產品照、儀器實測曲線截圖、標誌、曲線示意圖
preview/                    桌機與行動版截圖（供快速檢視）
```

## 檢視方式

直接雙擊 `index.html` 即可，字型已內嵌成 data URI，離線也能正常顯示。
若要模擬正式環境，可在這個資料夾執行 `python -m http.server 8000`，再開啟 `http://localhost:8000/`。

## 設計重點

- **主色取自儀器本體**：原廠示波截圖的螢光軌跡為青綠色（實測取樣 RGB 約 0,224,192），全站只用這一個強調色，其餘為冷灰紙底與近黑文字。
- **兩種字型的角色分工**：中文與正文用系統無襯線字，型號、量程、日期、參數用等寬字 JetBrains Mono，讓規格表讀起來像儀器面板。
- **版型不重複**：非對稱首屏、可篩選型號索引表、圖文左右交錯的產品詳解、規格對照表、曲線圖與實測截圖、可搜尋的資料庫、年度動態清單，十個區塊各用不同版面家族。
- **互動都對應真實任務**：型號分類篩選、解決方案分類＋關鍵字搜尋（搜尋會自動跨分類）、MOSFET 開啟電壓量測步驟可展開、語言偏好會記憶在瀏覽器。

## 內容維護

- **改文字**：`index.html` 內每個文字節點都成對出現 `<span class="zh">…</span><span class="en">…</span>`，只改其中一種語言不會影響另一種。
- **換圖片**：把新圖放進 `assets/img/`，覆蓋同名檔案即可；產品照建議白底、長邊 1200 px 以上。
- **改型號或量程**：型號索引表的每一列都有 `data-cat`（`tracer` / `analyzer` / `sorter` / `power`），對應上方篩選鈕；解決方案清單的每一筆有 `data-doc-cat` 與 `data-keys`（搜尋用的關鍵字）。
